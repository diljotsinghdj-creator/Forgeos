# Painted pieces (procedural, no image model)

Painted with **cloveric/claude-drawing-skill** (MIT, numpy + Pillow, CPU only), run with the owner's approval
(2026-11-14). The library is not vendored here; the scripts point to a local clone.

| File | What | Content |
|---|---|---|
| `letterpress_bill.py` | the film's timeline as a two-colour letterpress bill (red, then black, slightly out of register) | the film's own sourced dates |
| `kraft_ground.py` | kraft-board newspaper-collage ground (evidence file, red disc, SOURCED, tape, ransom letters, stamp) | our own words only; the real source scraps go on top in the page |

Each script saves its stages (`*_stages/`), so a piece can print or assemble itself on screen, stage by stage.
The ransom letters carry the library's own unreadable newsprint texture; no invented headline is legible anywhere.
