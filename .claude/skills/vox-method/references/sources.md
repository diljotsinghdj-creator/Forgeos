# Sources for the process research (P1–P45)

The reference files cite these as P1, P2, … Case studies list their own sources inside each file.

**How these were gathered (2026-11-12).**
- Every P-source was read **through search-result snippets only**: page fetches were blocked by the session's
  network allowlist.
- Attribution is as reliable as a snippet allows. Entries marked "attribution uncertain" or "low confidence" support
  only [I] statements.
- Verifying each against the full page is the first job of the next research pass (learning_protocol.md). Hosts to
  allow for that: niemanlab.org, storybench.org, theopennotebook.com, videoconsortium.org, schoolofmotion.com,
  pressgazette.co.uk, vox.com, and a transcript index such as rosetta.to.
